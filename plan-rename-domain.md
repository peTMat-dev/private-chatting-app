# Plan: Rename app.lenez.dev → cubcha.lenez.dev

Change the client-facing domain from `app.lenez.dev` to `cubcha.lenez.dev`. The API domain `api.lenez.dev` remains unchanged. Two source files need editing; build artifacts regenerate automatically.

## Steps

### Phase 1 — Code changes (this repo)

1. **`server/.env`** — Edit `CLIENT_ORIGINS`:
   - `https://app.lenez.dev` → `https://cubcha.lenez.dev`
   - `http://app.lenez.dev` → `http://cubcha.lenez.dev`

2. **`client/next.config.ts`** — Replace all 3 occurrences:
   - Hostname entry `"app.lenez.dev"` → `"cubcha.lenez.dev"`
   - `"https://app.lenez.dev"` → `"https://cubcha.lenez.dev"`
   - `"http://app.lenez.dev"` → `"http://cubcha.lenez.dev"`

3. **Rebuild** the Next.js client inside `client/`: `pnpm build`

### Phase 2 — Server infrastructure (VPS, outside this repo)

4. **DNS** — In the DNS provider dashboard for `lenez.dev`, add/rename the `A` record:
   - `app.lenez.dev` → `cubcha.lenez.dev` pointing to `194.163.177.24`

5. **Nginx** — Find the config with:
   ```
   grep -rl "app.lenez.dev" /etc/nginx/
   ```
   Edit the file and change `server_name app.lenez.dev;` → `server_name cubcha.lenez.dev;`

6. **SSL certificate** — Issue a new Let's Encrypt cert for the new hostname:
   ```
   certbot --nginx -d cubcha.lenez.dev
   ```

7. **Reload nginx**:
   ```
   nginx -t && systemctl reload nginx
   ```

## Relevant files

- `server/.env` — `CLIENT_ORIGINS` line (CORS allowed origins)
- `client/next.config.ts` — hostname allow-list / `allowedDevOrigins` block

## Files NOT changed (intentionally)

- `client/.env.local` — only references `api.lenez.dev`; no change needed
- `client/.next/` build artifacts — regenerated by rebuild in step 3

## Verification

1. Grep for `app.lenez.dev` in the repo — should return zero results outside `.next/`
2. Restart the Express server; confirm CORS allows requests from `cubcha.lenez.dev`
3. Check DNS propagation at dnschecker.org for `cubcha.lenez.dev`
4. Access `https://cubcha.lenez.dev` and confirm the app loads and API calls succeed

## Decisions

- `api.lenez.dev` and all server-side backend config are unchanged
- DNS/nginx/SSL are outside this repo and must be handled separately on the VPS
- The old `app.lenez.dev` DNS record can be removed once traffic is confirmed on the new domain
